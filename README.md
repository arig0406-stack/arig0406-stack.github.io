*Professional portfolio page of Alejandro Irala — process improvement, data and operations support. Available for remote and freelance work (UTC−3). The site has an English version: use the ES / EN switch at the top.*

## Qué incluye

- Servicios, método de trabajo, resultados, proyectos, trayectoria, formación y contacto.
- **Bilingüe (ES / EN)**: el idioma se elige con el botón de arriba, se recuerda entre visitas y se puede forzar con `?lang=en`.
- **CV descargable en formato ATS** ([cv/Alejandro-Irala-CV-ATS.pdf](cv/Alejandro-Irala-CV-ATS.pdf)), desde la portada y desde contacto.
- Si se imprime la página (Ctrl+P), sale con un diseño limpio, sin animaciones ni fondos oscuros.
- Responsive (escritorio, tablet y celular) y accesible: navegación por teclado, textos alternativos y respeto de "reducir movimiento".
- Metadatos para que el link se vea bien al compartirlo en LinkedIn o WhatsApp.

## Tecnología

HTML, CSS y JavaScript puro. Sin frameworks, sin dependencias, sin build. Publicado con GitHub Pages.

```
├── index.html                                  Página completa (estilos y script incluidos)
├── img/                                        Fotos
```
